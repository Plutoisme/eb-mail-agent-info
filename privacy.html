EB Gmail Agent

Privacy policy

EB Gmail Agent is a personal application used only by its owner to manage their own Gmail account. It is not offered as a public or multi-user service.

Information accessed and purpose

After Google OAuth authorization, the application can access email content, headers, attachments, threads, drafts, labels and mailbox information. It uses this information to provide the owner's requested email search, reading, drafting, sending and mailbox-management functions. Full Gmail access includes the ability to permanently delete messages.

Processing and sharing

Email and attachment processing uses a locally running AI model on the owner's equipment. Email data is not sent to external AI services. Google receives the authenticated API requests necessary to operate Gmail. Gmail data is not sold, used for advertising, or used to train general-purpose AI models. Email is transmitted to recipients when the owner instructs the application to send it.

Storage and retention

OAuth credentials and any email data downloaded by the agent are held in the owner's local environment. Retention depends on the owner's local configuration and actions; there is no separate hosted mailbox database operated by this website. Revoking OAuth access does not automatically remove existing local copies. The owner can remove local copies, logs and credentials through their local system.

Owner control

The owner can stop the application, revoke its access in Google Account connections, and delete locally stored data. Revocation prevents further API access with the revoked authorization. Email deletion performed through Gmail is subject to Gmail's behavior; permanent deletion cannot be undone by this application.

Website hosting

This website contains static application information and policy pages. It has no email login form, OAuth token collector or application analytics. Its hosting provider, GitHub Pages, may process ordinary web request information under GitHub's privacy statement. Gmail content and OAuth credentials are not published to this site or its source repository.

Google API Limited Use

EB Gmail Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Questions

The operator is the sole user. The operator's support contact is shown on the Google OAuth consent screen. Do not submit email content or credentials in public repository issues.

This policy will be updated before any change to the described data practices.
